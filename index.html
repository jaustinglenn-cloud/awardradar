🛠️ Step-by-Step GitHub Backend & iPhone PWA Setup Guide

Step 1 — Create Your GitHub Repository & Push the Bundle

Create a new repository at github.com/new named awardradar. Unzip the provided awardradar-repo.zip bundle and push index.html, searches.json, data/deals.json, requirements.txt, scripts/search_flights.py, and .github/workflows/flight_search.yml to the main branch.

Step 2 — Enable GitHub Pages & Actions Write Permissions

1. In your repo, go to Settings → Pages (GitHub Pages Docs) and set Source to Deploy from a branch → main / /(root).
2. Go to Settings → Actions → General → Workflow permissions and select Read and write permissions so the cron job can commit updated data/deals.json every 6 hours.

Step 3 — Add Your NTFY_TOPIC Secret & Install ntfy on iPhone

1. Install the free ntfy iOS App from the App Store and subscribe to your secret topic name above.
2. In your GitHub repo, go to Settings → Secrets and variables → Actions (Actions Secrets Guide) and create a repository secret named NTFY_TOPIC with that exact topic name.

Step 4 — Install AwardRadar to Your iPhone Home Screen

Open https://<your-username>.github.io/awardradar/ in iOS Safari, tap the Share icon (↑), and tap Add to Home Screen. AwardRadar launches full-screen with its custom radar icon and status bar styling.
